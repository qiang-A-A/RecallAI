PART 01

MVP 范围界定

MVP 目标是验证「错题录入 + AI 诊断 + 智能复习」的核心价值假设,不做大而全。用「砍掉什么」定义边界。

✅ MVP 包含(In Scope)

  • 错题录入:拍照 OCR(文字+公式)+ 手写板 + 文字粘贴,三类输入全支持
  • AI 诊断:知识点识别(LLM + 知识图谱 RAG),置信度 + 人工确认兜底
  • 错题管理:题库列表 / 筛选 / 标签 / 去重合并 / 删除
  • 智能复习:SM-2 间隔重复 + 每日清单 + 3 级提示梯度
  • 变式训练:基于薄弱考点的 1-3 题变式生成 + 质检 + 批改
  • 学习分析:周报(错题数/掌握率/错因 TOP5),不做实时大屏

❌ MVP 排除(Out of Scope)

  • 社区/UGC:错题分享广场、同学互评
  • 多人协作:家长端、老师班级管理(仅预留分享链接)
  • 专项辅导:名师视频、1v1 预约(B 端变现,仅埋入口)
  • 多端原生:仅小程序 + H5,不做 iOS/Android 原生
  • 离线全量:仅支持复习模块的本地降级缓存
  • 全学科图谱:首发覆盖「数学 + 物理 + 英语」三个学科

成功指标(North Star & Guardrail)

指标定义目标(上线 4 周)类型
周活跃复习率每周 ≥ 3 次复习的用户占比≥ 35%北极星
首日激活率完成 1 道错题录入 + 1 次复习≥ 40%北极星

PART 05

核心模块设计

四个高价值模块的实现要点,与业务流程文档中的 A1-A10 节点一一对应。

模块 1:错题录入管线(A1-A2)

异步 FastAPI + Celery

  • 上传:小程序端 COS 直传 → 回调携带 file_id → 创建 questions 占位记录(状态 pending)
  • OCR:PaddleOCR 文字行 + Pix2Text 公式块 → 合并为 content_json
  • 阈值:整体置信度 < 0.5 → 状态 need_review,前端展示「原图 + 可编辑文本」供修正
  • 回写:识别完成后通过订阅消息通知,用户可继续录入不阻塞
# 录入状态机
pending ──OCR成功──▶ processed
pending ──OCR失败/低置信──▶ need_review ──人工修正──▶ processed
processed ──用户删除──▶ deleted(软删)

模块 2:AI 知识点诊断(A3-A4)

异步 LLM + RAG

  • 检索:按学科取出知识图谱子图(JSON),作为 LLM 上下文;图谱节点含「定义 / 典型错因 / 关联题」
  • 推理:Prompt 要求输出 Top-3 候选 + 置信度 + 推理依据(可解释性)
  • 判定:Top1 置信度 ≥ 0.7 → 直通;0.5-0.7 → 候选确认页;< 0.5 → 无标签收录 + 人工队列
  • 回填:写入 question_kp,同步更新 user_kp_stats
# 诊断 Prompt 骨架(截断展示)
你是一名学科诊断专家。给定题目与知识图谱,判断考查的核心知识点。
输出 JSON:
{"candidates": [{"kp_id", "name", "confidence", "reason"}...],
 "type": "选择|解答|证明|计算", "difficulty": "易|中|难"}

模块 3:智能复习引擎(S2 / A5-A6)

同步 SM-2 + 调度器

  • 每日清单:凌晨调度 due_date ≤ today 的题目,按优先级(临近考试 > 高频错 > 薄弱知识点)排序,截断 20 题
  • 作答交互:3 级提示梯度由 LLM 预生成缓存,前端按点击逐级解锁
  • 自评回写:已掌握 → 延长间隔;模糊/不会 → 重置 interval = 1d 并归因
  • 倦怠保护:7 天未复习用户 → 推送降频 + 文案切换(见算法章节)

模块 4:变式生成(A7-A8)

异步 LLM + 质检器

  • 触发:D2 判定条件(模糊 ≥ 2 次 / 同考点错题 ≥ 3 / 主动强化 / 考前 7 天)
  • 生成:以「原题 + 卡点步骤 + 目标难度」为上下文,一次生成 3 题(难度 1→2→3)
  • 质检:四维评分(答案唯一性 / 题干清晰度 / 与原题相似度 / 考点覆盖),任一 < 0.7 触发重生成,最多 2 次
  • 批改:过程分 + 错因归类 + 与原题「思维差异」对比,回写掌握度(+0.3 / 高亮)
PART 06

核心算法

三个关键算法:MVP 版 SM-2 间隔重复、错题去重(向量相似度)、复习调度优先级。

算法 1:SM-2 间隔重复(MVP 简化版)

def sm2_update(state, grade):
    # grade: 0=不会, 1=模糊, 2=已掌握 (由自评映射)
    if grade == 0:                       # 不会 → 重置
        state.reps = 0; state.interval = 1
        state.ease_factor = max(1.3, state.ease_factor - 0.2)
    elif grade == 1:                     # 模糊 → 缩短间隔
        state.reps += 1; state.interval = 1
    else:                                # 已掌握 → 指数递增
        state.reps += 1
        if state.reps == 1: state.interval = 1
        elif state.reps == 2: state.interval = 3
        else: state.interval = round(state.interval * state.ease_factor)
        state.ease_factor = min(2.8, state.ease_factor + 0.1)
    state.due_date = today + timedelta(days=state.interval)
    return state

ease_factor 初始 2.5,区间 [1.3, 2.8]。MVP 期不引入 IRT/DDL 优先级融合模型,保留 priority 权重字段供后续升级。

算法 2:错题去重(向量相似度)

def dedup_check(question, threshold=0.95):
    emb = embedding_model.encode(question.text)          # bge-large-zh, 1024d
    sim = pgvector.search(emb, user_id=question.user_id)
    if sim > threshold:
        target = sim.best_match
        target.error_count += 1                    # 合并,保留重复错误次数
        question.dedup_group_id = target.id
        return target
    return question

按 user_id 分桶检索(隔离用户数据),HNSW 索引,单次检索 < 20ms。

算法 3:复习调度优先级

priority = 0.40 * exam_proximity + 0.30 * error_frequency + 0.20 * kp_weakness + 0.10 * overdue_days
# exam_proximity: 距目标考试天数归一化(越近越高,考前 7 天封顶)
# error_frequency: 该题累计错误次数 / 复习次数
# kp_weakness:     user_kp_stats.mastery 反比
# 每日清单:due_date ≤ today 内按 priority 降序取前 20

PART 08

质量与安全

质量保障

  • AI 可解释性:诊断输出必须带 reasoning 字段,前端可折叠查看「为什么诊断这个考点」
  • 回归测试集:预置 200 题标注题库,每次 LLM/OCR 模型升级跑回归,诊断采纳率 < 75% 不发版
  • 降级策略:LLM 超时 60s → 返回「默认考点 + 人工修正」,不阻塞录入;OCR 失败降级文字模式
  • 幂等:AI 回调接口带 request_id 去重,防止队列重投重复入库

安全与合规

  • 数据隔离:所有查询强制带 user_id 条件,行级权限
  • 未成年人:目标用户含高中生(14-18 岁),需监护人授权页 + 隐私政策明示;收集最小化(不采集真实姓名/住址)
  • LLM 内容:变式题与讲解输出过「内容安全过滤」(腾讯云内容安全 API),拦截不当内容
  • 传输与存储:HTTPS 全链路;题目图片 COS 私有读 + 签名 URL;敏感字段加密存储
  • 合规备案:小程序需 ICP 备案 + 隐私协议;涉及 AI 生成内容需履行算法备案义务(上线前法务确认)
PART 09

里程碑与验收

8 周交付,3 个里程碑,每个里程碑结束均有可演示版本与验收标准。团队建议:后端 2 人 + 前端 2 人 + AI 1 人 + 产品 1 人。

W1-W3 · M1地基 + 录入闭环

账号体系、错题录入(拍照 OCR / 文字)、题库管理、去重合并、COS 直传

✅ 验收:可拍照录入一道数学错题 → OCR → 入库 → 列表可见;OCR 成功率 ≥ 80%

W4-W6 · M2AI 诊断 + 智能复习

知识点诊断(RAG + LLM)、候选确认、SM-2 复习引擎、每日清单、3 级提示、订阅消息推送

✅ 验收:完整跑通「录入→诊断→复习→自评→下次复习」闭环;诊断采纳率 ≥ 75%

W7-W8 · M3变式训练 + 学习分析

变式生成 + 质检 + 批改、周报、掌握度矩阵、报告分享链接(埋家长/老师入口)

✅ 验收:薄弱考点 10 分钟内可完成 3 题变式训练;周报数据与 review_logs 一致

风险与成本

公式 OCR 准确率不足高录入体验差,首日激活率不达标双引擎(开源+云 API)可切换;低置信自动转人工修正引导

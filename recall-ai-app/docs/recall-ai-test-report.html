2发现的问题(测试中发现并已修复)

严重移动端(≤390px)顶部导航横向溢出 31px

品牌区 84px + 5 个导航图标(45px×5)+ 头像 32px + padding 48px = 421px > 390px,页面出现横向滚动条。违反开发规划「≤640px 底部 Tab」的响应式要求。

修复:TopNav.vue 移动端压缩按钮内边距(px-3.5 → px-2)、品牌文字隐藏(hidden sm:inline)、导航 overflow-x-auto。已重新构建并验证 390px 无溢出。已验证

严重离线版导出触发 CORS 报错

静态版点「导出」时向 file:///C:/api/v1/questions/export/pdf 发起真实请求,被浏览器 CORS 拦截,console 报 2 个错误,导出失败。

修复:client.ts 的 exportPdf 增加 OFFLINE 分支,离线时生成模拟导出内容。已重新构建并验证 console 错误清零。已验证

优化移动端未实现底部 Tab 导航

390px 下仅右下角 FAB(录入/复习),无开发规划要求的底部 Tab;导航靠顶部横向滚动可达全部页面,功能可用但移动体验未达最佳。

建议:后续迭代按开发规划「≤640px 底部 Tab + safe-area-inset-bottom」实现,当前优先级:P2。

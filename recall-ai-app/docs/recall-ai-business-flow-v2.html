U1触发错题录入入口用户操作
触发首页「+」按钮 / 拍照悬浮球 / 微信分享到小程序 / 相册导入
处理唤起录入页,自动携带默认学科上下文与最近使用教材版本
输出进入录入流程
⚠ 异常分支未登录 → 跳转「子流程① 首次使用引导」完成账号绑定;无相机权限 → 降级为相册/文字录入
U2选择录入方式交互用户操作
触发录入页呈现 3 个 Tab(拍照 / 手写 / 文字)
处理拍照:实时取景 OCR 预览;手写:电子手写板 + 笔迹识别;文字:粘贴题干与选项(支持 LaTeX)
输出题目原始素材提交 AI 管线
⚠ 异常分支文件 > 10MB / 非图片格式 → 提示压缩或引导切换文字模式;夜间光线不足 → 开启补光引导
A1OCR + 公式识别AI 管线第 1 步AI 处理
触发收到 U2 提交的原始素材
处理版面分析 → 文本行识别 → 公式区域识别(LaTeX 化)→ 结构化合并题干/选项/图
输出结构化题干 + 置信度分项(文本 0.9 / 公式 0.8)
⚠ 异常分支置信度 < 0.5 → 触发 U3 人工修正,原图叠加可编辑文本;公式大面积失败 → 标记「公式待确认」
A2题型分类AI 管线第 2 步AI 处理
触发A1 结构化结果就绪
处理基于题干特征(选项存在/问句/解答词)分类:题型 × 学科 × 难度三级
输出{选择题 | 解答题 | 证明题 | 计算题} + {易 | 中 | 难}
A3知识点诊断核心价值点AI 处理
触发A2 分类完成
处理RAG 检索学科知识图谱 → 多知识点打分排序 → 输出 Top-K 候选 + 推理依据
输出主知识点 + 关联知识点 + 考点链路 + diagnosis_confidence
⚠ 异常分支跨学科边界(数学-物理双考点)→ 输出并列双候选交由 U3 确认
D1置信度判定质量闸门AI 判定
触发A3 产出诊断结果
处理diagnosis_confidence ≥ 0.7 直通入库;否则进入候选确认环节
输出布尔判定 + 候选列表(供 UI 渲染)
U3候选知识点确认人机协同用户操作
触发D1 判定为低置信度,自动唤起
处理Top-3 候选卡片 + 一键「都不对」自助补录;选择结果回写 A3
输出用户锁定的最终知识点
⚠ 异常分支用户连续 3 次「都不对」→ 降级为无标签收录,进入人工审核队列
S1错题入库错题管理核心系统处理
触发U3 确认或 D1 直通
处理写入错题库:生成唯一 ID,挂载元数据(学科/章节/教材版本/知识点 ID/难度/错因/时间)
输出可检索条目 + 全文索引更新
⚠ 异常分支题干向量相似度 > 0.95 → 判定重复,自动合并保留 2 次错误记录(防刷题重复)
S2编排复习计划智能复习起点系统处理
触发每日 00:30 调度 + 实时事件(新题入库/用户主动复习)
处理SM-2 间隔重复算法 + 优先级队列(临近考试 / 高频错题 / 薄弱知识点加权)
输出当日复习清单(数量上限保护:默认 ≤ 20 题)
⚠ 异常分支连续 7 日未复习 → 学习倦怠保护:降低推送频次 + 启动轻量提醒(防流失)
A5生成提示梯度教学法设计AI 处理
触发S2 清单到期推送
处理为每道错题生成 3 级提示梯度:①核心考点 ②思路引导 ③完整解析(按需逐步解锁)
输出复习卡片数据(图文混排)
U4 / U5复习与自评闭环关键交互用户操作
触发进入复习 Tab / 点击推送通知 / 桌面 Widget
处理先作答(5s 内无思路则逐级给提示)→ 标记 → 自评:已掌握 / 模糊 / 不会
输出自评结果 + 可选文字备注
⚠ 异常分支跳过未自评 → 24h 后「未完成」再提醒一次;中途锁屏 > 5min → 暂停计时并保存进度
A6更新记忆曲线算法引擎AI 处理
触发U5 自评提交
处理SM-2 更新 ease factor 与 interval;掌握 → 延长;模糊/不会 → 重置 interval = 1d
输出下次复习时间 + 难度系数
D2变式训练判定强化触发AI 判定
触发满足任一:①同一错题「模糊/不会」≥ 2 次 ②同知识点错题 ≥ 3 道 ③用户主动点「我要强化」 ④考前 7 天薄弱扫描命中
处理进入「子流程③ 变式训练」;否则按常规路径更新曲线
输出变式训练任务(1-3 题,难度阶梯)或 跳过
S3写入学习数据数据底座系统处理
触发每次复习/变式/批改动作完成
处理事件流入湖(lakehouse),更新错题主表 / 用户画像表 / 复习日志表
输出可分析数据集(支撑 A9 与 A10)
A9学习数据分析价值输出AI 处理
触发周/月定时 + 用户主动查看
处理统计 + 趋势 + 知识点掌握度矩阵;识别高频错因 TOP5 / 进步最快 / 退步考点
输出周报/月报数据 + 个性化改进建议条目
A10模型反哺画像自增强回路AI 处理
触发用户对报告点赞/忽略 + 历史表现积累
处理微调个性化诊断阈值 / 推送权重 / 变式难度系数
输出用户级个性化策略,实现「千人千面」,回流至 S2 / A3

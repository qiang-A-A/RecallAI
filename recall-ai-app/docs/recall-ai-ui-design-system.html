01

色彩规范

以 Notion 紫罗兰为品牌底座,靛蓝紫渐变专用于 AI 能力;语义色全程一致,浅底 tint 用于标签/徽章/选中态。

Token色值用途示例
--primary#5645d4品牌主色 / 主要 CTA / 选中态主操作
--primary-pressed#4534b3主按钮按下态-
--ai-start / --ai-end#6366f1 → #8b5cf6AI 渐变:诊断 / 对话 / 玻璃拟态AI 能力
--brand-navy#0a1530深色面:Hero / 深色模式 / 空状态-
--charcoal#37352f标题文字(暖黑)-
--slate#5d5b54次级文字-
--success#1aae39已掌握 / 成功已掌握
--warning#dd5b00模糊 / 待复习模糊
--error#e03131不会 / 删除 / 错误不会
--info#0075de用户操作 / 链接 / 录入录入

中性灰阶(--surface-soft → --muted)与柔和 tint(--tint-lavender 等)沿用 Notion 体系,深色模式将 --surface-soft/--charcoal 等映射到品牌 navy 系即可。

02

字体规范

中文场景用系统字体栈;数字与公式使用 tabular-nums 等宽对齐,避免跳动;正文行高 1.6 适合长时间阅读。

04

圆角规范

圆角语义化:越大的元素圆角越大。按钮 8px · 卡片 14px · 弹窗 16px · 玻璃卡片 16px。全站不混用非标圆角。

页面布局规范

顶部导航(60px)+ 双栏内容区(左 200px 导航/列表 + 右自适应)。内容容器 max-width 1180px,12 列栅格,列间距 16px。

左栏 200px

复习页(专注)

单题居中,四周留白 64px+,无侧栏干扰,最大化专注。

看板页(信息)
